0. Что требуется и как это связано

Задание 3 — это «путь пользователя»: вошёл → нашёл товар → открыл карточку → положил в корзину → оформил заказ. Весь код — в файлах программы «Чудо Обувь» (страница «Код и формы программы», там же можно скачать архив).

Шаг пользователяФайлОкно
ВходLoginForm.csВход
Каталог, поиск, фильтр, сортировкаMainForm.csКаталог
Выбор размера и количестваProductForm.csКарточка
Оформление заказаCartForm.csКорзина
Сначала должно работать задание 2 (каталог показывается). Если каталога нет — возвращайтесь туда.

Нарисовать окно мышкой

Правой по проекту → Add → Form (Windows Forms) → LoginForm. Toolbox → перетащите Label (Text = «Логин:»), TextBox (Name = txtLogin) и две Button («Войти», «Без входа»). Окну: Text = «Чудо Обувь — Вход», StartPosition = CenterScreen.
Как создать обработчик клика мышкой: на форме дважды щёлкните по кнопке — Visual Studio сама создаст метод Имя_Click и откроет его. В программе из архива эта подписка уже лежит в файле LoginForm.Designer.cs строкой this.btnOk.Click += new System.EventHandler(this.btnOk_Click); — студия пишет её сама, когда вы дважды щёлкаете по кнопке.

7. Оформление заказа — по шагам

Транзакция — это «всё или ничего»: либо заказ записан и товар списан, либо вообще ничего не изменилось. Это защищает от ситуации «заказ есть, а товар не списан».

            using (var c = Db.Open())
            using (var t = c.BeginTransaction())      // всё или ничего
            {
                try
                {
                    int orderId = (int)Db.Cmd(c, "INSERT INTO Заказы (Код_пользователя) OUTPUT INSERTED.Код_заказа VALUES (@u)",
                        new object[] { "@u", clientId }, t).ExecuteScalar();
                    foreach (var l in Session.Cart)
                    {
                        // Списываем остаток; если не хватило — 0 строк изменено.
                        int n = Db.Cmd(c, "UPDATE Товарные_позиции SET Количество = Количество - @q WHERE Код_позиции = @s AND Количество >= @q",
                            new object[] { "@q", l.Qty, "@s", l.StockItemId }, t).ExecuteNonQuery();
                        if (n == 0) throw new Exception("Не хватает на складе: " + l.Name);
                        Db.Cmd(c, "INSERT INTO Строки_заказов (Код_заказа, Код_позиции, Количество, Цена_за_единицу) VALUES (@o, @s, @q, @p)",
                            new object[] { "@o", orderId, "@s", l.StockItemId, "@q", l.Qty, "@p", l.Price }, t).ExecuteNonQuery();
                    }
                    t.Commit();
                }
                catch { t.Rollback(); throw; }
            }
            Session.Cart.Clear();
            MessageBox.Show("Заказ оформлен.", "Готово", MessageBoxButtons.OK, MessageBoxIcon.Information);
            Close();
        }
  1. Создаём заказ в Заказы (дата ставится сама) и получаем его номер.
  2. Для каждой строки: UPDATE … Количество = Количество - @q WHERE … Количество >= @q. Если товара не хватило — изменено 0 строк → исключение → Rollback (всё отменяется).
  3. Пишем строку в Строки_заказов с ценой на момент заказа (Цена_за_единицу).
  4. Commit — фиксируем.
  5. Очищаем корзину и закрываем окно; каталог сам обновится.
Гость заказ оформить не может: кнопка «Корзина» у него скрыта.
