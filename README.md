## 💻 Программа «Чудо Обувь»

**Технологии:** C# · Windows Forms · .NET Framework 4.8 · Microsoft SQL Server.

| Кто вошёл | Что может |
|---|---|
| Гость | смотреть каталог |
| Пользователь | поиск, фильтр, сортировка, карточка товара, корзина, оформление заказа |
| Менеджер | всё выше + список заказов, состав, добавление и удаление заказа, выбор клиента |
| Администратор | всё менеджерское + смена даты заказа и удаление позиции |
| Статистика (менеджер и администратор) | окно «Статистика заказов»: все заказы, выручка, средний чек (задание 5) |

**Окна:** `LoginForm` → `MainForm` (каталог) → `ProductForm` → `CartForm`, а для менеджера и администратора ещё `OrdersForm`.

### Два архива

| Архив | Для чего |
|---|---|
| `downloads/ChudoObuv.zip` | **Основной.** Упрощённая программа, по ней написан весь разбор: исходники, окна (`*.Designer.cs`), `.sln`, ресурсы, `Database.sql`, `Проверка.sql`, `Собрать.bat`, `Руководство_пользователя.docx` |
| `downloads/ChudoObuvOrders.zip` | **Полная версия** со слоями `Data`, `Models`, `Forms`, `UI` и дополнительными окнами, включая `StatisticsForm` (задание 5) |

### Как запустить программу

1. Откройте `ChudoObuvOrders.sln` в Visual Studio — база `Чудо_Обувь.mdf` уже лежит в папке проекта, настраивать ничего не нужно.
2. Нажмите **F5**. Строка подключения в `App.config` уже настроена на локальную базу `Чудо_Обувь.mdf` — вписывать сервер не нужно.
3. Для запуска `.exe` рядом с ним должны лежать папка `Resources` и база `Чудо_Обувь.mdf` (строка подключения в `ChudoObuvOrders.exe.config` уже настроена на локальную базу).

> Проект в Visual Studio должен называться **`ChudoObuvOrders`**: под этим именем мастер подключения сохраняет строку подключения, которую читает `Db.cs`.

> Если база удалена или повреждена — её несложно собрать заново **мышкой, без SQL-запросов**: пошагово со скриншотами это показано в разборе задания 1 (разделы 5–8: файл базы в проекте → MS SQL Server → таблицы → данные) и в задании 2 (раздел 6: подключение к программе). Файлы `Database/Database.sql` и `Проверка.sql` лежат в архиве справочно.

## 🗃 База данных

8 таблиц, все названия на русском и совпадают с заголовками файлов импорта:

`Роли` · `Пользователи` · `Категории` · `Товары` · `Размеры` · `Товарные_позиции` · `Заказы` · `Строки_заказов`

Итоговая сумма заказа в базе не хранится — она считается из позиций (`Количество × Цена_за_единицу`). Так же строится и окно статистики (задание 5): `SUM` по строкам каждого заказа.
