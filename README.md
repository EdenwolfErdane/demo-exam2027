## 💻 Программа «Чудо Обувь»

**Технологии:** C# · Windows Forms · .NET Framework 4.8 · Microsoft SQL Server.

| Кто вошёл | Что может |
|---|---|
| Гость | смотреть каталог |
| Пользователь | поиск, фильтр, сортировка, карточка товара, корзина, оформление заказа |
| Менеджер | всё выше + список заказов, состав, добавление и удаление заказа, выбор клиента |
| Администратор | всё менеджерское + смена даты заказа и удаление позиции |

**Окна:** `LoginForm` → `MainForm` (каталог) → `ProductForm` → `CartForm`, а для менеджера и администратора ещё `OrdersForm`.

### Два архива

| Архив | Для чего |
|---|---|
| `downloads/ChudoObuv.zip` | **Основной.** Упрощённая программа, по ней написан весь разбор: исходники, окна (`*.Designer.cs`), `.sln`, ресурсы, `Database.sql`, `Проверка.sql`, `Собрать.bat` |
| `downloads/ChudoObuvOrders.zip` | **Полная версия** со слоями `Data`, `Models`, `Forms`, `UI` и дополнительными окнами |

### Как запустить программу

1. В SQL Server Management Studio выполните `Database/Database.sql` (создаётся база `Чудо_Обувь`).
2. В `App.config` в параметре `Data Source` впишите **имя своего сервера**.
3. Соберите программу:
   - откройте `ChudoObuvOrders.sln` в Visual Studio → **Release** → **Build Solution**.
4. Для запуска `.exe` рядом с ним должна лежать папка `Resources`, а имя сервера нужно прописать в `ChudoObuvOrders.exe.config`.

> Проект в Visual Studio должен называться **`ChudoObuvOrders`**: под этим именем мастер подключения сохраняет строку подключения, которую читает `Db.cs`.

`Database/Проверка.sql` проверяет базу: количество строк в таблицах, товары без остатков, лишние временные таблицы и результат запроса каталога.

## 🗃 База данных

8 таблиц, все названия на русском и совпадают с заголовками файлов импорта:

`Роли` · `Пользователи` · `Категории` · `Товары` · `Размеры` · `Товарные_позиции` · `Заказы` · `Строки_заказов`

Итоговая сумма заказа в базе не хранится: она считается из позиций (`Количество × Цена_за_единицу`).
